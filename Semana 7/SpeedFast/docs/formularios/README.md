# Formularios originales de IntelliJ

Estos archivos conservan los diseños anteriores a la migración a Maven como referencia.
No participan en la compilación y sus cambios no modifican las ventanas de la aplicación.
La interfaz activa se inicializa en `inicializarComponentes()` de cada clase en
`src/main/java/vista`, usando exclusivamente componentes y layouts de Java Swing.
